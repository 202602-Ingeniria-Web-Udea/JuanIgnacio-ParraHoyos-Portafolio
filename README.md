# Portafolio de Juan Ignacio Parra

https://juan-ignacio-parra-hoyos.vercel.app/

Proyecto creado con Next.js, React, TypeScript, Tailwind CSS e Iconify.

## Ejecutar

```bash
npm install
npm run dev
```

## Estructura

```text
app/components/
├── atoms/
├── molecules/
└── organisms/
utils/
└── data.ts
```

Los componentes siguen el estilo utilizado en clase: `import React`, arrow functions con `const index`, props con nombres concretos y exportación por defecto.

Los colores y gradientes se modifican desde las variables de `app/globals.css`.
